# Correcciones UX — Indicadores, proyectos y administración

## Indicadores

La pantalla de Seguimiento distingue dos acciones: Editar indicador, para modificar configuración, y Registrar avance, para agregar resultados periódicos. Los avances existentes se conservan al editar.

Para crear un indicador se requieren únicamente un período de gestión y un área o unidad organizativa responsable. Objetivo institucional y proyecto son relaciones opcionales.

Los nuevos avances abren en estado Enviado para que formen parte del resultado. Borrador permanece disponible para registros que todavía no deben entrar en el cálculo.

## Proyectos

Gestión Organizacional > Proyectos muestra una llamada a la acción visible para Crear proyecto. Utiliza el formulario de proyectos existente y mantiene el modelo compartido con Donaciones.

## Usuarios y accesos

Los roles existentes se conservan. Gestión Organizacional vuelve a mostrar un acceso directo a Usuarios y accesos para administradores y superadministradores en escritorio y móvil.
